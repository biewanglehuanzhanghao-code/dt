# 世界地图 v0.4.2

本版继续修改已有 v0.4 地图插件。优先处理：首页入口、无聊天时刷新地图、位置变化提醒。

## 安装更新

1. 解压整个 ZIP，把里面的文件和 assets、data 文件夹全部上传到原 GitHub 仓库，替换同名文件，然后提交。
2. 仓库根目录必须直接看见 manifest.json、world-map.js、world-map.css、README.md、assets/ 和 data/。不要把 ZIP 文件本身上传后当作插件安装。
3. 酒馆扩展管理里更新原插件，再刷新浏览器页面。确认版本显示 0.4.2。旧 index.js、bootstrap.js 和 style.css 若仍留在仓库里，本版不会加载它们，不必为了删除它们额外操作。
4. 不用开始对话、不用连接 API，先看首页右下方有没有 🗺️。点击进入地图，再点“刷新状态”。

本包不带最外层插件文件夹，解压后的内容直接上传到仓库根目录。

## 两种地图

自由地图：没有选中角色聊天时默认使用。不依赖 API，点一次刷新推进世界时间半小时，从有作息配置的角色中选取最多 3–6 人，根据可用时间段、活动权重和停留时长更新。只有一个测试角色时最多更新一个。角色可能继续办公或休息，不保证每次点击都换地点。地点确实改变才显示“已经抵达”提醒。

剧情地图：打开已有角色或群聊对话后使用。点击刷新才调用当前酒馆的模型和聊天上下文。没有新增 API 地址或 Key 配置，也没有新增其他外部服务。主界面顶部的“自由地图 / 剧情地图”按钮可切换；无角色聊天时仅可使用自由地图。切换不调用 API，两种地图的状态分开保存。

首页的酒馆欢迎消息不会被当作角色剧情。打开地图也不会触发模型请求。

自由地图的状态跟随酒馆扩展设置保存，剧情地图跟随对应聊天保存。若酒馆完全没有提供上下文接口，自由地图仍能在当前页面运行，但此时进度只留在本次页面会话内。

## 当前素材与规则

保留原来的一张地图、14 个地点和阿莫克温。顶部目前只有一个地图标签；多图入口逻辑保留，但不添加未提供的区域图片。

阿莫克温的自由活动是暂定测试作息：白天办公、检查操练、巡视岗哨；用餐时段可去食堂，夜间偏向休息。规则放在 data/world.json 的 routine 中，人物和地点未写死到模拟代码。你不需要编辑代码，后续可提供正式作息由我修改文件。

每轮半小时是当前简化时间步长，尚不计算道路与精确行程。人物状态卡、头像更换和拖动位置沿用原版。

## 入口修复

- 不再通过 bootstrap.js 动态导入第二个模块。world-map.js 是一个可按普通脚本或模块加载的完整脚本，不使用 import/export/import.meta。
- 用实际 world-map.js 的 URL 定位素材，不要求仓库必须叫某个名字。
- 先建立悬浮标和地图框，再读取地图。创建入口不等待模型、聊天、酒馆上下文接口或 world.json。
- 悬浮标带内联位置和显示样式；配置加载失败时保留入口并允许重试。
- 扩展设置容器延迟出现时补挂设置入口。

这些修改针对已识别的加载脆弱点；没有手机浏览器日志，仍不能确定旧版在手机上未显示的唯一原因。

## 验证范围

已通过脚本语法检查和模拟上下文测试：首页欢迎消息识别、无聊天无 API 刷新、角色位置变化与提醒去重、自由/剧情进度隔离、聊天内自由模式、保存状态重载、最多 3–6 人更新、无上下文运行、配置失败前创建入口、失败后重试。

当前环境缺少浏览器可执行程序，尚未在真实浏览器或用户的 SillyTavern 1.18.0 / build 反代环境验证。不能据此声称手机入口已经修好。

若安装后仍没有 🗺️，请发酒馆“扩展管理”中这款插件的一行截图（包含版本与启用状态），优先确认新版文件确实加载，不必再次生成对话。如果入口有了但地图报错，截图错误文字即可。
